# 📱 SMS Spam Detector

A machine learning web app that classifies SMS messages as **Spam** or **Not Spam** using NLP techniques and a trained model. Built with **Python**, **Scikit-learn**, and deployed using **Streamlit** in a Docker container.

---

## 🚀 Demo

[Live on Hugging Face Spaces](https://huggingface.co/spaces/Bichu0077/sms-spam-detector) 

---

## 🧠 Model Details

- **Algorithm**: Multinomial Naive Bayes
- **Feature Extraction**: CountVectorizer (Bag of Words)
- **Dataset**: SMS Spam Collection Dataset (UCI Repository)
- **Accuracy**: ~98%

## 🛠️ Tech Stack

- Python 3
