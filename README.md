# 📱 SMS Spam Detector

A machine learning web app that classifies SMS messages as **Spam** or **Not Spam** using NLP techniques and a trained model. Built with **Python**, **Scikit-learn**, and deployed using **Streamlit** in a Docker container.

---

## 🚀 Demo

[Live Demo](https://sms-spam-detector-bdozhp2zelakecxjnvqsa3.streamlit.app/)

---

## 🧠 Model Details

- **Algorithm**: Multinomial Naive Bayes  
- **Feature Extraction**: CountVectorizer (Bag-of-Words model)  
- **Dataset**: SMS Spam Collection Dataset (Kaggle / UCI Repository)  
- **Accuracy**: ~98% on validation set  

---

## 🛠️ Tech Stack

- Python 3  
- Scikit-learn  
- Pandas  
- Streamlit  
- Docker  
- Streamlit Cloud (for deployment)

---

## 📦 Features

- Classifies SMS messages in real time  
- Clean and responsive UI built with Streamlit  
- Fully containerized using Docker for seamless deployment  
- High-performing spam detection using NLP and ML
